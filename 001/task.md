Task 001: Employee Management System
Objective: Create an employee management system using Core Java and OOP fundamentals.

What we implemented:
- EmployeeDetails class with id, name, department, and salary.
- Constructor to initialize employee details.
- Private fields and getter methods.
- updateSalary() method with validation and a boolean return value.
- Main class to create employees, update salaries, and verify results.
Concepts involved:
Concept	How we used it
Classes and objects	Created EmployeeDetails objects for different employees.
Constructors	Initialized employee data when creating objects.
Encapsulation	Used private fields and getters to control access.
final keyword	Prevented changes to id, name, and department after initialization.
Conditional statements	Validated salary updates and rejected zero or negative values.
Return values	Returned true or false to indicate whether a salary update succeeded.
Object independence	Each employee object maintained its own salary.
Key takeaway: Encapsulation protects object state, while methods control how that state changes.
